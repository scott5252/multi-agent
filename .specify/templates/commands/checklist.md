# /speckit.checklist

Generate a review checklist tailored to the current feature and aligned with the
constitution.

## Mandatory Checklist Areas

- user-scenario and requirement completeness
- durability and failure-recovery coverage
- tenant isolation and quota coverage
- contract, versioning, and lineage coverage
- security, secret, and tool-policy coverage
- artifact storage, approval/resume, and observability coverage when relevant
- testing evidence, coverage target, README updates, and quickstart validation

## Output Rule

The checklist must help reviewers confirm that the spec, plan, and tasks are
ready for implementation without reinterpreting the constitution.
