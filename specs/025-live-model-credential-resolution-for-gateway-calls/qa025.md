# QA025: Live Model Credential Resolution For Gateway Calls

## Goal

Validate that provider probes and runtime gateway calls resolve model provider
credentials from safe secret references only at call time.

This QA pass proves that raw credential values do not enter provider records,
gateway context, persisted diagnostics, rendered admin pages, logs, README
guidance, or QA evidence.

## What This Guide Covers

- Local setup for `multi_agent_platform_qa025`.
- Local-principal login as `platform-admin`.
- Model provider admin pages under `/admin/model-providers`.
- OpenAI provider references and safe probe behavior.
- Local OpenAI-compatible no-auth behavior for allowlisted local endpoints.
- `ModelGateway` runtime credential resolution.
- Missing or unresolved credential failures.
- Safe gateway attempts, physical attempts, retry summaries, breaker summaries, and usage metadata.
- Redaction scans for fake raw credential fixture values.
- Focused tests and full quality gates.

## Pass Criteria

- Provider connection records contain reference ids only.
- Provider probes resolve references at call time.
- Gateway calls resolve references at call time.
- Credential failures avoid adapter calls.
- Persisted evidence uses `secret_reference_invalid` for missing or unresolved credentials.
- No raw resolved credential value appears in persisted or rendered evidence.
