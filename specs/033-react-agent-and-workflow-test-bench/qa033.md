# QA033 API And Database Guide

## Goal

QA033 proves that the React agent and workflow test bench is safe, scoped, typed, and useful for tenant administrators and platform reviewers.

The route under review is `/admin/app/test-bench`.

The primary dashboard contract is `/admin/app/test-bench/bootstrap.json`.

The suite list contract is `/admin/app/test-bench/suites`.

The suite detail contract is `/admin/app/test-bench/suites/suite-qa033-daily-briefing`.

The run list contract is `/admin/app/test-bench/runs.json`.

The run detail contract is `/admin/app/test-bench/runs/run-qa033-failing.json`.

The publish gate contract is `/admin/app/test-bench/gates.json`.

The artifact metadata contract is `/admin/app/test-bench/artifacts/artifact-qa033-summary.json`.

The audit contract is `/admin/app/test-bench/audit.json`.

Suite save actions post to `/admin/app/test-bench/suites`.

Case save actions post to `/admin/app/test-bench/suites/suite-qa033-daily-briefing/cases`.

Run launch actions post to `/admin/app/test-bench/suites/suite-qa033-daily-briefing/runs`.

Publish gate refresh actions post to `/admin/app/test-bench/gates/qa033-required-suite/refresh`.

Expected: administrators can author suite and case metadata without raw fixtures.

Expected: administrators can bind suites to current workflow draft revisions.

Expected: administrators can launch deterministic mock-mode runs.

Expected: approved live dependency probe attempts fail closed in local QA.

Expected: React renders backend-owned pass, fail, stale, running, unavailable, and denied states.

Expected: React does not decide pass or fail locally.

Expected: test bench output is generated by backend contracts and generated TypeScript.

Expected: local validation does not call live Auth0.

Expected: local validation does not call Telegram.

Expected: local validation does not call model providers.

Expected: local validation does not call external connector tools.

Expected: local validation does not resolve real credential values.

What this proves: reviewers can validate suite authoring, deterministic run execution, diagnostic evidence, publish gate readiness, and governance audit records without exposing sensitive runtime data.

## How To Use This Guide

Run commands from the repository root.

When a command writes a `/tmp/qa033-*` file, keep it until reviewer notes are complete.

Use `qa033_ui.md` for the browser walkthrough.

Use `qa033_user_guide.md` for a plain-language manual review script.

Do not use real provider credentials.

Do not connect to live providers.

Do not call Telegram.

Do not call external tools.

Do not paste secrets into suite or case fields.

Do not paste raw prompts, raw completions, private messages, memory contents, connector request bodies, connector response bodies, raw tool outputs, transcripts, stack traces, local paths, artifact storage paths, or tenant data from another organization into any QA note.

Expected: all command output is local and deterministic.

Expected: test bench diagnostics are safe summaries and artifact references.

Expected: credential references appear as labels and policy summaries only.

What this proves: the test bench route can be reviewed safely by developers and QA reviewers.

## Environment

Copy the QA033 environment:

```bash
cp specs/033-react-agent-and-workflow-test-bench/.env.qa033 .env
```

Expected: `.env` references `multi_agent_platform_qa033`.

Expected: `.env` references `.data/qa033-artifacts`.

Expected: `.env` references only `qa033/` fake secret references.

Install Python dependencies:

```bash
uv sync
```

Build React admin assets:

```bash
cd frontend/admin
npm install
npm run build
cd ../..
```

Expected: Vite writes `src/multi_agent_platform/web_admin/static/react/manifest.json`.

Reset the QA database:

```bash
docker compose up -d postgres
docker compose exec -T postgres sh -c 'dropdb -U postgres --if-exists multi_agent_platform_qa033 && createdb -U postgres multi_agent_platform_qa033'
uv run alembic upgrade head
```

Seed local tenants:

```bash
docker compose exec -T postgres psql -U postgres -d multi_agent_platform_qa033 -v ON_ERROR_STOP=1 -c "INSERT INTO tenants (tenant_id, slug, display_name, status, created_at, updated_at) VALUES ('11111111-1111-1111-1111-111111111111', 'acme', 'Acme', 'active', CURRENT_TIMESTAMP, CURRENT_TIMESTAMP), ('22222222-2222-2222-2222-222222222222', 'globex', 'Globex', 'active', CURRENT_TIMESTAMP, CURRENT_TIMESTAMP) ON CONFLICT (slug) DO NOTHING"
```

Create evidence directories:

```bash
mkdir -p .data/qa033-artifacts output/playwright/qa033_ui
```

Capture the tenant dashboard contract:

```bash
curl -sS -H "X-Local-Principal: tenant-admin-acme" "http://127.0.0.1:8000/admin/app/test-bench/bootstrap.json?tenant_id=11111111-1111-1111-1111-111111111111" > /tmp/qa033-tenant-test-bench.json
```

Capture run detail evidence:

```bash
curl -sS -H "X-Local-Principal: tenant-admin-acme" "http://127.0.0.1:8000/admin/app/test-bench/runs/run-qa033-failing.json?tenant_id=11111111-1111-1111-1111-111111111111" > /tmp/qa033-run-detail.json
```

Expected: `/tmp/qa033-tenant-test-bench.json` contains `Daily briefing release gate`.

Expected: `/tmp/qa033-run-detail.json` contains `Blocked side-effect assertion failed`.

Expected: neither file contains fake secret values, raw prompts, raw completions, raw transcripts, local paths, artifact storage paths, or Globex tenant data in the Acme tenant view.

## Troubleshooting

If `/admin/app/test-bench` returns 401, confirm `.env.qa033` was copied to `.env` and use local login or the `X-Local-Principal` header.

If the React page shows loading forever, rebuild assets with `cd frontend/admin && npm run build`.

If a mutation returns `stale_conflict`, use the current target revision `workflow-draft-rev-qa033-current`.

If a run launch returns `validation_error`, check that `safe_mode` is `mock_model_tools` or `side_effect_disabled_gateway`.

If a live dependency probe is denied, that is expected in local QA.

If a screenshot shows fake secret values, raw runtime payloads, local paths, or Globex data in an Acme view, stop and treat it as a regression.

If QA database reset fails, verify PostgreSQL is running through Docker Compose.

If Playwright cannot find `Test Bench`, confirm the API process started after the QA033 env copy.

Expected: troubleshooting never requires live credentials.

Expected: troubleshooting never requires real external calls.
