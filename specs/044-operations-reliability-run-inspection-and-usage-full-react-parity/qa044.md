# QA044: Operations, Reliability, Run Inspection, And Usage Full React Parity

## Goal

QA044 proves that the operations, reliability, admin run inspection,
user-facing run compatibility, and usage analytics browser surfaces are now
React-first without losing the backend-owned JSON APIs that feed the React
workspaces.

The key review question is simple: old Jinja browser URLs must no longer render
Jinja templates, while safe direct links still carry the user to the correct
React route with tenant, run, export, panel, and filter context preserved.

What this proves: platform operators and tenant reviewers can keep old
bookmarks, saved filters, export links, and run links during the migration
without exposing secrets, raw payloads, cross-tenant data, or stale Jinja pages.

## What This Guide Covers

This guide covers Spec 044 manual and automated QA for these surfaces.

1. `/admin/operations` redirects to `/admin/app/operations`.
2. `/admin/reliability/ui/` redirects to the React reliability panel.
3. `/admin/reliability/ui/breakers` redirects to the React breaker panel.
4. `/admin/reliability/ui/dead-letters` redirects to the React dead-letter panel.
5. `/admin/runs` redirects to the React run search panel.
6. `/admin/runs/{workflow_run_id}` redirects to the React run detail panel.
7. `/admin/runs/{workflow_run_id}/replay` redirects for browser callers and
   keeps JSON replay behavior for API callers.
8. `/runs`, `/runs/new`, and `/runs/{run_id}` redirect to React channel run
   surfaces when the principal is authorized.
9. `/admin/usage` redirects to `/admin/app/usage`.
10. `/admin/usage/exports/{usage_export_request_id}` redirects to the React
    export detail route after authorization is checked.
11. Retained JSON APIs continue to return safe summaries for React.
12. Retired template and static paths stay deleted and unreferenced.

## Troubleshooting

If `/admin/app/operations` shows an unauthenticated state, visit
`http://127.0.0.1:8000/auth/local-login?redirect_to=/admin/app/operations` and
choose `platform-admin`.

Expected: local login sets `map_local_principal` and returns to the React
operations workspace.

If usage JSON returns 403 for tenant checks, confirm the request header is
`X-Local-Principal: tenant-admin-acme` and the tenant id is the Acme id above.

Expected: same-tenant usage is allowed and cross-tenant usage is denied.

If Playwright cannot find `Operations`, rebuild the React bundle with
`cd frontend/admin && npm run build`, restart the API, and rerun the Playwright
validation command.

Expected: the React bundle under `src/multi_agent_platform/web_admin/static/react`
contains the latest routes.

If the retirement scanner fails, inspect the reported path before adding it
back. A surviving template reference means deletion-grade evidence is incomplete
and Spec 044 must not advance.

Expected: the fix is either a redirect, a safe compatibility response, or a
documented reason to stop.
