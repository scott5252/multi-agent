# QA062 Guide: Spec 062 - Design Review Coordinator And Iteration Loop

## Goal

This guide verifies the design review coordinator and iteration loop.

Spec 062 launches review rounds from durable design review sessions.

Each coordinator round reviews exactly one immutable design revision.

Each coordinator round creates one DB-backed runtime workflow run.

The runtime graph remains acyclic.

Iteration happens by launching another round run for a new revision.

The coordinator records reviewer assignments.

The coordinator records safe reviewer verdicts.

The coordinator evaluates four-of-five or three-of-four quorum.

The coordinator requires zero blocking issues for approval.

The coordinator creates a development handoff when quorum passes.

The coordinator creates the next immutable revision when revision is required.

The coordinator pauses for manual resolution when evidence is incomplete,
contradictory, blocked, or max rounds are reached.

Expected: a valid launch creates one round and one runtime run.

Expected: replaying a launch idempotency key returns the same round.

Expected: an approved quorum creates a ready handoff.

Expected: a non-passing complete round creates a new revision when rounds remain.

Expected: blocking evidence pauses for manual resolution.

Expected: manual revise creates another immutable revision.

Expected: Globex cannot read or operate on Acme coordinator sessions.

Expected: QA evidence does not contain raw prompts, completions, provider
payloads, authorization headers, credentials, memory contents, or raw tool
payloads.
