# QA036: React Channel, Telegram, And Briefing Preferences

## Goal

Validate the additive React workspace for channel readiness, Telegram tenant setup, natural-language aliases, identity linking, bounded delivery diagnostics, safe run status, and Daily Intelligence Briefing preference profiles.

This guide is for local reviewer evidence. It uses `AUTH_MODE=local_principal`, deterministic Acme and Globex tenants, fake secret references, mock-safe Telegram delivery state, and the QA036 database `multi_agent_platform_qa036`.

No command in this guide should contact real Telegram, Auth0, model providers, external tools, or production credential systems.

## What This Guide Covers

- React shell and bootstrap access for `/admin/app/channels`.
- Platform administrator channel and Telegram readiness review.
- Tenant administrator Acme-scoped readiness, configuration, alias, link-token, identity, delivery, and safe run status checks.
- Tenant user briefing preference profile checks.
- Preference import and export metadata checks.
- Cross-tenant denial and unauthenticated denial checks.
- Redaction scans over `/tmp/qa036-*` evidence and Playwright screenshots.
- Focused backend, frontend, generated-contract, and full project quality gates.

## Troubleshooting

- `401 missing local principal header or cookie`: use the browser login flow in `qa036_ui.md` or include `X-Local-Principal` in curl.
- `403` for Acme dashboard: confirm `tenant_id=11111111-1111-1111-1111-111111111111` and principal `tenant-admin-acme`.
- Globex appears in Acme evidence: stop and investigate tenant scope handling before continuing.
- Link-token evidence contains `pair-code`: delete the evidence file and rerun the sanitized curl command.
- `React admin unavailable`: rebuild frontend assets with `cd frontend/admin && npm run build`.
- `table tenants does not exist`: rerun `uv run alembic upgrade head`.
- `tenant row missing`: rerun the seed command in the Environment section.
- Playwright cannot find `Validate Acme`: confirm the current browser principal is `tenant-admin-acme` or `platform-admin`.
- The worker exits immediately: inspect `/tmp/qa036-worker.log` when using the QA runner.
- Redaction scan fails on a local path: move reviewer scratch files out of `/tmp/qa036-*` before rerunning scans.
