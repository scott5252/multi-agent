# QA060 UI Walkthrough: Spec 060 - Design Review Domain Foundation

## Goal

This walkthrough verifies browser-visible and OpenAPI-visible evidence for the
design review domain foundation.

Spec 060 is primarily a backend foundation.

The current browser evidence therefore focuses on the served OpenAPI document,
the local-login path, and safe manual inspection of JSON route output.

The walkthrough confirms the new route family is discoverable without exposing
raw prompts, completions, private messages, memory contents, tool payloads, or
secret values.

Expected: `/openapi.json` includes `design-reviews`.

Expected: `/openapi.json` includes create, list, detail, revision, round,
quorum, manual-decision, and handoff route metadata.

Expected: local login remains available for browser-first manual review.

Expected: screenshots are safe to attach to QA evidence.

## How To Use This Guide

Run the environment setup before opening the browser.

Use local-principal authentication.

Capture screenshots only after the page has settled.

Keep reviewer notes under `/tmp/qa060-ui-notes.md`.

Use `/tmp/qa060-ui-action-evidence.txt` for final screenshot paths.

What is happening: the browser loads the FastAPI OpenAPI document generated by
the same router used by the JSON APIs.

Why this matters: route discovery is the first browser-visible contract for a
backend foundation that does not yet have a dedicated React workspace.

Expected: route discovery and API responses agree.

Expected: visible evidence remains redaction-safe.

## Environment Setup

Use `specs/060-design-review-domain-foundation/.env.qa060`.

Start from the repository root.

```bash
cp specs/060-design-review-domain-foundation/.env.qa060 .env
uv sync
docker compose up -d postgres
```

```bash
docker compose exec -T postgres sh -c 'dropdb -U postgres --if-exists multi_agent_platform_qa060 && createdb -U postgres multi_agent_platform_qa060'
uv run alembic upgrade head
uv run python scripts/qa/seed_design_review_qa060.py
```

Expected: seed output says `Seeded QA060 design review live records`.

Start the API if reviewing manually.

```bash
uv run uvicorn multi_agent_platform.api.main:app --host 127.0.0.1 --port 8000
```

Start the worker in a second terminal if the full manifest is not managing it.

```bash
uv run python -m multi_agent_platform.workers.main
```

Expected: `http://127.0.0.1:8000/health/live` returns success.

Expected: `http://127.0.0.1:8000/health/ready` returns success.

## Browser Walkthrough

Open local login.

```text
http://127.0.0.1:8000/auth/local-login?redirect_to=/openapi.json
```

What is happening: local-principal login sets a local reviewer identity.

Why this matters: QA can validate browser routes without external auth.

Expected: the login form is available.

Expected: the form includes local principals.

Choose `platform-admin`.

Expected: the browser redirects to `/openapi.json`.

Expected: the page body contains `design-reviews`.

Expected: the page body contains `/admin/design-reviews/sessions`.

Expected: the page body contains `/admin/design-reviews/rounds/{round_id}`.

Capture the automated OpenAPI screenshot.

```bash
uv run python scripts/qa/run_playwright_ui.py specs/_autopilot/scenario-enhancement-roadmap/060-design-review-domain-foundation/validation.yml --start-processes
```

Expected: `output/playwright/qa060_ui/qa060-scenario-enhancement-smoke.png`
exists.

Open the session list route in the browser after local login.

```text
http://127.0.0.1:8000/admin/design-reviews/sessions?tenant_id=11111111-1111-1111-1111-111111111111
```

What is happening: the API returns Acme design review session metadata.

Why this matters: the route must render only safe summaries and identifiers.

Expected: the JSON response includes `items`.

Expected: the JSON response includes `state`.

Expected: the JSON response includes the seeded QA060 safe summary.

Expected: the response does not include `Authorization:`.

Expected: the response does not include provider credential values.

Open the Globex list route while signed in as Globex, or use curl for a precise
header check.

```bash
curl --fail --silent --show-error -H 'X-Local-Principal: tenant-admin-globex' 'http://127.0.0.1:8000/admin/design-reviews/sessions?tenant_id=22222222-2222-2222-2222-222222222222' > /tmp/qa060-globex-empty.json
```

Expected: `/tmp/qa060-globex-empty.json` contains `"kind":"empty"` or the
equivalent JSON spacing.

Open an Acme detail route after creating a session through the API.

```bash
curl --fail --silent --show-error -X POST -H 'Content-Type: application/json' -H 'X-Local-Principal: tenant-admin-acme' 'http://127.0.0.1:8000/admin/design-reviews/sessions' -d '{"tenant_id":"11111111-1111-1111-1111-111111111111","request_summary":"QA060 browser review session.","quorum_policy_key":"four_of_five_no_blockers","idempotency_key":"qa060-browser-session"}' > /tmp/qa060-browser-create.json
```

Expected: `/tmp/qa060-browser-create.json` contains a
`design_review_session_id`.

What is happening: the browser reviewer creates a minimal safe session.

Why this matters: idempotent creation is the MVP workflow for the domain
foundation.

Use the id from `/tmp/qa060-browser-create.json` to open the detail route.

Expected: the detail response includes one revision.

Expected: the handoff state is `pending` for the newly created session.

Expected: no unsafe raw content appears.

## Troubleshooting

If local login is unavailable, confirm the API process started with `.env.qa060`.

If `/openapi.json` does not include `design-reviews`, confirm the
`admin_design_review_router` is included in the app.

If Acme list returns `401`, confirm the local-principal header or login cookie.

If Acme list returns `403`, confirm the tenant id matches the selected
principal.

If Globex list shows Acme records, reset the QA database immediately and rerun
the seed script.

If Playwright times out, inspect `/tmp/qa060-api.log`.

If the worker exits, inspect `/tmp/qa060-worker.log`.

If the screenshot is empty, rerun Playwright after confirming `/health/live`.

Expected: rerunning the UI validation is safe.

Expected: rerunning create-session with the same idempotency key replays.
