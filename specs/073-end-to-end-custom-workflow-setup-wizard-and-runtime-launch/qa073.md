## Required Automated Evidence

Run setup and migrations.

```bash
cp specs/073-end-to-end-custom-workflow-setup-wizard-and-runtime-launch/.env.qa073 .env
uv sync
docker compose up -d postgres
docker compose exec -T postgres sh -c 'dropdb -U postgres --if-exists multi_agent_platform_qa073 && createdb -U postgres multi_agent_platform_qa073'
uv run alembic upgrade head
```

Run focused frontend evidence.

```bash
cd frontend/admin && npm test -- workflowSetupWizard WorkflowBuilderPage UserRunPage DesignReviewWorkspacePage
cd frontend/admin && npm run typecheck
cd ../..
```

Run backend and repository quality evidence.

```bash
uv run ruff check .
uv run ruff format --check .
uv run mypy src
uv run pytest --cov=src/multi_agent_platform --cov-report=term-missing --cov-fail-under=90
```

Run generated contract and frontend build evidence.

```bash
uv run python scripts/frontend/generate_admin_react_types.py --check
cd frontend/admin && npm ci
npm test
npm run build
cd ../..
```

Run Spec Kit validation evidence.

```bash
bash .specify/extensions/qa-docs/scripts/bash/validate-qa-documents.sh specs/073-end-to-end-custom-workflow-setup-wizard-and-runtime-launch
uv run python scripts/qa/run_spec_qa.py specs/_autopilot/workflow-setup-roadmap/073-end-to-end-custom-workflow-setup-wizard-and-runtime-launch/validation.yml
uv run python scripts/qa/run_playwright_ui.py specs/_autopilot/workflow-setup-roadmap/073-end-to-end-custom-workflow-setup-wizard-and-runtime-launch/validation.yml --start-processes
```

Run curl regression evidence.


## Troubleshooting

If login fails, verify `AUTH_MODE=local_principal`.
If Workflows fails, check `/tmp/qa073-api.log`.
If worker-dependent state is stale, check `/tmp/qa073-worker.log`.
If the database is missing, recreate `multi_agent_platform_qa073`.
If save reports stale conflict, reload the draft and retry.
If evidence is stale, save the requirement first and launch a new deterministic run.
If publish is blocked, read backend-owned findings.
If Design Reviews does not select the custom workflow, confirm the workflow is published.
If runtime launch does not prefill, confirm the link contains `workflow_id`.
If Playwright fails on a selector, inspect the screenshot in `output/playwright/qa073_ui`.
If a real external call is attempted, stop and file a blocker.
If raw unsafe text appears, stop and file a blocker.
