# QA034 API And Database Guide

## Goal

QA034 proves that the React user and tenant membership administration workspace is safe, scoped, typed, auditable, and useful for platform and tenant administrators.

The route under review is /admin/app/memberships.

The primary dashboard contract is /admin/app/memberships/bootstrap.json.

Invitation actions post to /admin/app/memberships/invitations.

Principal link actions post to /admin/app/memberships/principals/link.

Role grant actions post to /admin/app/memberships/role-grants.

Role revoke actions post to /admin/app/memberships/role-grants/grant-qa034-acme-maya/revoke.

Principal status actions post to /admin/app/memberships/principals/principal-qa034-maya/suspend.

Tenant membership status actions post to /admin/app/memberships/memberships/membership-qa034-acme-maya/removed.

Access history reads from /admin/app/memberships/access-history.json.

Audit timeline reads from /admin/app/memberships/audit.json.

Expected: platform administrators can view authorized tenant labels across tenants.

Expected: tenant administrators see only their own tenant scope.

Expected: invitation replay returns the original invitation summary.

Expected: role grant denials return safe validation details.

Expected: principal linking is platform-authorized only.

Expected: suspend, reactivate, remove, and revoke actions require confirmation.

Expected: access history is bounded and safe.

Expected: audit records contain safe summaries and audit references.

Expected: local validation does not call live Auth0.

Expected: local validation does not deliver email.

Expected: local validation does not call model providers.

Expected: local validation does not call Telegram.

Expected: local validation does not call external connector tools.

Expected: local validation does not resolve real credential values.

Expected: generated TypeScript contracts match backend schemas.

What this proves: reviewers can validate user directory, invitations, role grants, status actions, access history, tenant isolation, and audit evidence without exposing unsafe identity data.

## Environment

Copy the QA034 environment:

```bash
cp specs/034-react-user-and-tenant-membership-administration/.env.qa034 .env
```

Expected: .env references multi_agent_platform_qa034.

Expected: .env references .data/qa034-artifacts.

Expected: .env references only qa034/ fake secret references.

```bash

```

```bash

```

Expected: Vite writes src/multi_agent_platform/web_admin/static/react/manifest.json.

Reset the QA database:

```bash
docker compose up -d postgres
docker compose exec -T postgres sh -c 'dropdb -U postgres --if-exists multi_agent_platform_qa034 && createdb -U postgres multi_agent_platform_qa034'
uv run alembic upgrade head
```

Seed local tenants:

```bash
docker compose exec -T postgres psql -U postgres -d multi_agent_platform_qa034 -v ON_ERROR_STOP=1 -c "INSERT INTO tenants (tenant_id, slug, display_name, status, created_at, updated_at) VALUES ('11111111-1111-1111-1111-111111111111', 'acme', 'Acme', 'active', CURRENT_TIMESTAMP, CURRENT_TIMESTAMP), ('22222222-2222-2222-2222-222222222222', 'globex', 'Globex', 'active', CURRENT_TIMESTAMP, CURRENT_TIMESTAMP) ON CONFLICT (slug) DO NOTHING"
```

Create evidence directories:

```bash
mkdir -p .data/qa034-artifacts output/playwright/qa034_ui
```

Capture the platform dashboard contract:

```bash
curl -sS -H "X-Local-Principal: platform-admin" "http://127.0.0.1:8000/admin/app/memberships/bootstrap.json" > /tmp/qa034-platform-memberships.json
```

Capture the tenant dashboard contract:

```bash
curl -sS -H "X-Local-Principal: tenant-admin-acme" "http://127.0.0.1:8000/admin/app/memberships/bootstrap.json?tenant_id=11111111-1111-1111-1111-111111111111" > /tmp/qa034-tenant-memberships.json
```

```bash
curl -sS -X POST -H "Content-Type: application/json" -H "X-Local-Principal: tenant-admin-acme" "http://127.0.0.1:8000/admin/app/memberships/invitations?tenant_id=11111111-1111-1111-1111-111111111111" -d '{"email":"invite.replay@example.test","requested_roles":["tenant_user"],"tenant_id":"11111111-1111-1111-1111-111111111111","idempotency_key":"invite-ui-qa034-replay"}' > /tmp/qa034-invite-replay.json
```

## Troubleshooting

If /admin/app/memberships returns 401, confirm X-Local-Principal or local login is set.

If tenant scope returns 403, confirm the tenant ID matches the local principal catalog.

If React assets are missing, rerun npm run build in frontend/admin.

If generated types drift, rerun uv run python scripts/frontend/generate_admin_react_types.py.

If a mutation returns confirmation_required, submit the confirmed payload shown in this guide.

If a role request returns validation_error, confirm the actor is allowed to assign that scope.

If evidence contains unsafe identity text, stop and fix the backend projection before taking screenshots.

If QA database setup fails, recreate only multi_agent_platform_qa034.

If Playwright cannot log in, confirm AUTH_MODE=local_principal.

Expected: failures are deterministic and local.
