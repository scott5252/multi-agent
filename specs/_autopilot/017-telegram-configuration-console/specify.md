Add a server-rendered Telegram Configuration Console for platform admins and authorized tenant admins. The console must let administrators view Telegram channel readiness, configure non-secret Telegram settings through safe secret references, validate webhook configuration, manage tenant-specific Telegram enablement, inspect linked Telegram identities without exposing private chat content, issue and revoke one-time link tokens, see recent safe delivery and webhook diagnostics, and understand whether protected Telegram commands are ready for use. The feature must build on existing Spec 006 channel behavior, local-principal admin test mode, Auth0 authorization, admin shell navigation, audit/redaction helpers, secret providers, reliability retries/breakers, and existing Telegram webhook/link-token services. It must never store or display real bot tokens, webhook secrets, private messages, raw prompts, run results, or unauthorized tenant data. Include tenant isolation, role boundaries, stale form conflict recovery, redaction-safe screenshots, docs, PR review notes, testing instructions, and at least 90 percent coverage.
