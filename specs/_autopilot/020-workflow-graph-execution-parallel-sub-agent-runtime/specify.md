Add workflow graph execution for published workflow bundles. The runtime worker must load the published bundle document, execute role nodes in dependency order, fan out independent branches in parallel, apply join policies such as all_success, quorum, first_success, and manual_resolution, invoke agent and sub-agent runtime profiles through the existing ModelGateway and policy services, persist per-node run steps, checkpoints, handoffs, side-effect intents, approvals, timeline events, partial failure summaries, and final structured outputs. The first flagship scenario is the Daily Intelligence Briefing workflow: Telegram starts one orchestrator run, four scout sub-agents run in parallel, their outputs join, a focus recommender runs after the join, and a synthesis node produces a final briefing. Cross-tenant access must fail closed, execution must be idempotent on resume, and no raw secrets or raw tool payloads may be rendered.
