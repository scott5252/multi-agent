# QA035 API And Database Guide

## Goal

QA035 proves that the React usage and cost analytics workspace is safe, scoped, typed, auditable, and understandable for platform and tenant administrators.

The route under review is /admin/app/usage.

The primary dashboard contract is /admin/app/usage/bootstrap.json.

Event drilldowns read from /admin/app/usage/events.json.

Export creation posts to /admin/app/usage/exports.

Export detail reads from /admin/app/usage/exports/35000000-0000-0000-0000-000000000035.json.

Expected: platform administrators can view authorized platform usage and tenant rollups.

Expected: tenant administrators see only their active tenant scope.

Expected: default filters use the last 7 days.

Expected: the dashboard shows total tokens, estimated cost, usage event count, latency, unavailable usage, and confidence coverage.

Expected: trend buckets separate confirmed, estimated, partial, and unavailable usage.

Expected: rollups are available for provider, model, workflow, agent, sub-agent, prompt, execution mode, principal, tenant, graph node, gateway operation, physical attempt, and governed tool.

Expected: event drilldowns are bounded to safe rows.

Expected: exports contain a safe filter snapshot, artifact reference, checksum prefix, row count, requester label, scope label, and audit reference.

Expected: cross-tenant tenant-admin export requests return a safe denied status.

Expected: local validation does not call live model providers.

Expected: local validation does not call live Auth0.

Expected: local validation does not call Telegram.

Expected: local validation does not call external connector tools.

Expected: local validation does not resolve real credential values.

Expected: generated TypeScript contracts match backend usage schemas.

What this proves: reviewers can validate usage totals, cost estimates, attribution rollups, drilldowns, exports, tenant isolation, and redaction without exposing unsafe run content.

## Troubleshooting

If the API returns 401, confirm .env was copied from .env.qa035 and the X-Local-Principal header is present.

If the API returns 403 for tenant-admin-acme, confirm the request tenant_id is the Acme tenant id.

If the platform dashboard does not show Globex, confirm the platform-admin local principal has usage:read.

If the tenant dashboard shows Globex, stop and treat it as a tenant-isolation blocker.

If export creation returns denied for Acme, confirm the request filter uses the Acme tenant id.

If export creation returns completed for a Globex filter while signed in as tenant-admin-acme, stop and treat it as a tenant-isolation blocker.

If generated TypeScript check fails, rerun scripts/frontend/generate_admin_react_types.py and inspect generated reactAdminApi.ts drift.

If frontend tests fail, inspect the usage component named in the Vitest output.

If Playwright cannot find Usage and Cost Analytics, rebuild React assets and restart the API.

If the redaction scan finds unsafe markers, delete the generated evidence, fix the active Spec 035 source, and rerun the capture command.

Expected: troubleshooting never requires real credentials or live providers.
