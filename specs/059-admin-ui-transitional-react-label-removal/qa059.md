# QA059 Guide: Spec 059 - Admin UI Transitional React Label Removal

## Goal

This guide verifies that the production admin browser UI now presents itself as
Admin, not as an implementation-era product label.

Spec 059 is the final cleanup gate for the remove-mock-data roadmap.

It proves the shell, fallback host, route metadata, migration evidence, domain
pages, generated contracts, and reviewer docs no longer expose blocked
transitional labels to users.

The gate still permits narrow implementation context for generated identifiers,
historical evidence ids, and developer-only migration evidence.

The allowed implementation context is recorded in the transitional label gate.

The blocked product label examples are `React Admin`, `React admin`,
`React-only`, `React route`, and similar user-visible phrasing.

Expected: ordinary users see Admin product terminology.

Expected: platform reviewers can still trace historical implementation evidence.

Expected: no raw secrets, prompts, completions, private messages, or local paths
are present in QA artifacts.

Expected: the route scanner reports zero blocked findings.

Expected: Playwright screenshots show Admin-facing labels.

## Troubleshooting

If QA docs fail, check heading names and line-count minimums.

If the route scanner reports blockers, run `uv run python scripts/qa/verify_transitional_labels_qa059.py`.

If `React Admin` appears in a route response, search production-visible source
files and replace it with Admin terminology.

If the allowed reference count is zero, verify that the projection still records
generated identifiers, historical evidence ids, and developer-only context.

If Playwright cannot find `Skill lifecycle`, rerun the QA seed script.

If Playwright cannot find `Transitional label gate`, verify the migration page
requests `/admin/app/migration/transitional-labels.json`.

If generated type checks fail, rerun `uv run python scripts/frontend/generate_admin_react_types.py`.

If curl regression fails, review `.data/curl_test_runs/qa059-after-spec`.

If tenant denial leaks Globex in a response body, stop and treat it as a blocker.

If any command writes a production reference, stop and remove the unsafe value.

Expected: troubleshooting does not require a Git commit.
