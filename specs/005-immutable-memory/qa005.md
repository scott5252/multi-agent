# QA Guide For Spec 005

This guide tests the full Spec `005` immutable versioned memory flow. It is
self-contained and does not require any files from earlier specs.

## 1. What You Are Testing

Spec `005` delivers:

- append-only memory scopes and versions
- current-head retrieval for workflow execution
- stale-head rejection for racing or resumed writes
- canonical JSON hashes and preserved prior versions
- replay and diff endpoints for reviewer investigation
- content-free audit views
- runtime source links for run, step, bundle, digest, and child lineage
- QA artifacts, docs, testing instructions, and PR notes

## 5. Create Initial Memory

```bash
curl -sS -X POST http://127.0.0.1:8000/memory/versions \
  -H "X-Local-Principal: tenant-admin-acme" \
  -H "Content-Type: application/json" \
  -d '{
    "scope": {
      "workflow_lineage_id": "workflow.qa005-memory",
      "agent_key": "triage-agent",
      "memory_key": "patient-preferences"
    },
    "assert_no_current_head": true,
    "content": {
      "preferred_contact": "sms",
      "removed_fields": {"$memory_removed": ["legacy_phone"]}
    },
    "change_reason": "initial preference capture",
    "change_summary_redacted": "Captured preferred contact channel"
  }'
```

Success looks like:

- HTTP `201`
- `version.version_sequence` is `1`
- `version.previous_memory_version_id` is absent
- `head_advanced` is `true`
- response includes `scope.memory_scope_id` and `version.memory_version_id`

Save those values as `memory_scope_id` and `version_1_id`.

## 6. Retrieve Current Head

```bash
curl -sS \
  "http://127.0.0.1:8000/memory/head?workflow_lineage_id=workflow.qa005-memory&agent_key=triage-agent&memory_key=patient-preferences" \
  -H "X-Local-Principal: tenant-admin-acme"
```

Verify:

- `has_memory` is `true`
- returned head id equals `version_1_id`
- content hash matches the initial write response

Missing scope check:

```bash
curl -sS \
  "http://127.0.0.1:8000/memory/head?workflow_lineage_id=workflow.qa005-missing&agent_key=triage-agent&memory_key=patient-preferences" \
  -H "X-Local-Principal: tenant-admin-acme"
```

Expected: `has_memory` is `false`.

## 7. Create A Successor Version

```bash
curl -sS -X POST http://127.0.0.1:8000/memory/versions \
  -H "X-Local-Principal: tenant-admin-acme" \
  -H "Content-Type: application/json" \
  -d '{
    "scope": {
      "workflow_lineage_id": "workflow.qa005-memory",
      "agent_key": "triage-agent",
      "memory_key": "patient-preferences"
    },
    "expected_current_version_id": "{version_1_id}",
    "content": {
      "preferred_contact": "email",
      "timezone": "America/New_York",
      "removed_fields": {"$memory_removed": ["legacy_phone"]}
    },
    "change_reason": "user updated preference",
    "change_summary_redacted": "Updated preferred contact channel"
  }'
```

Save the returned id as `version_2_id`.

Verify:

- `version_sequence` is `2`
- `previous_memory_version_id` equals `version_1_id`
- current head now points to `version_2_id`

## 8. Validate Stale-Head Handling

Repeat the successor write using `version_1_id` again as
`expected_current_version_id`.

Expected:

- HTTP `409`
- response detail includes `stale_expected_head`
- version 1 and version 2 remain retrievable and unchanged

## 9. History, Replay, And Diff

History:

```bash
curl -sS "http://127.0.0.1:8000/memory/scopes/{memory_scope_id}/versions?include_content=false" \
  -H "X-Local-Principal: tenant-admin-acme"
```

Replay version 1:

```bash
curl -sS http://127.0.0.1:8000/memory/versions/{version_1_id}/replay \
  -H "X-Local-Principal: tenant-admin-acme"
```

Diff version 1 and version 2:

```bash
curl -sS -X POST http://127.0.0.1:8000/memory/diffs \
  -H "X-Local-Principal: tenant-admin-acme" \
  -H "Content-Type: application/json" \
  -d '{
    "base_memory_version_id": "{version_1_id}",
    "compare_memory_version_id": "{version_2_id}"
  }'
```

Expected:

- history returns newest version first
- replay returns the exact version 1 snapshot
- diff reports `/preferred_contact` as changed and `/timezone` as added

## 10. Audit Redaction

```bash
curl -sS "http://127.0.0.1:8000/memory/audit?memory_scope_id={memory_scope_id}" \
  -H "X-Local-Principal: tenant-admin-acme"
```

Verify audit events include action, outcome, actor/source, ids, hashes, and
redacted summaries. Audit responses must not include raw values such as `sms`,
`email`, or `America/New_York`.

## 11. Cross-Tenant Denial

```bash
curl -i -sS http://127.0.0.1:8000/memory/versions/{version_1_id} \
  -H "X-Local-Principal: tenant-admin-globex"
```

Expected: HTTP `404` or fail-closed denial semantics. The Globex principal must
not see Acme memory content.
