# QA042: Spec 042 - Skill Registry And Tool Diagnostics Full React Parity And Jinja Removal

## Goal

This guide verifies that Spec 042 moves skill registry and SkillExecutionGateway diagnostics browser journeys to React and removes skill-owned Jinja templates safely.

Reviewers should prove that `/admin/app/skills` is the browser entry point for package publication, tenant discovery, installation readiness, credential configuration, smoke-test refresh, binding eligibility, connector diagnostics, audit evidence, and legacy redirect evidence.

Reviewers should also prove that old `/admin/skill-registry/ui/*` and `/admin/skill-execution/ui/diagnostics` browser URLs redirect to React or return safe non-Jinja errors after the old templates have been deleted.

What this proves: platform and tenant operators keep their skill lifecycle workflows while the active skill browser surface no longer renders Jinja templates.

## What This Guide Covers

- React skill lifecycle dashboard and legacy route mapping contracts.
- Platform package candidate, validation, publish, grant, quarantine, and withdrawal actions.
- Tenant package discovery, installation, credential readiness, smoke-test readiness, and binding eligibility actions.
- SkillExecutionGateway diagnostics, explicit refresh behavior, and mocked-safe connector summaries.
- Old skill registry and diagnostics route redirects with safe query preservation.
- Deleted skill registry and skill execution template evidence.
- Auth0-shaped route authorization through backend tests.
- Local-principal browser behavior through Playwright.
- Tenant isolation, denied states, stale revision recovery, and redaction checks.
- QA evidence paths under `/tmp/qa042-*`, `.data/qa042-artifacts`, and `output/playwright/qa042_ui`.

## Troubleshooting

- If login loops, confirm `LOCAL_PRINCIPAL_COOKIE_NAME=map_local_principal`.
- If a tenant route returns `401`, confirm the `X-Local-Principal` header or local login principal.
- If a tenant route returns `403`, confirm `tenant_id` matches the selected principal.
- If React assets 404, run `cd frontend/admin && npm run build`.
- If diagnostics look empty, confirm `SKILL_EXECUTION_CONNECTOR_MODE=mock`.
- If old routes return `200` with a Jinja page, stop and inspect the router conversion.
- If redaction scans fail, keep the evidence file and inspect the backend schema validators before continuing.
