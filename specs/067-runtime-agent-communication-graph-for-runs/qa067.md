# QA067 Guide: Runtime Agent Communication Graph For Runs

## Goal
QA067 proves that an authorized administrator can inspect a workflow run as a read-only runtime communication graph built from existing durable runtime evidence.
The graph must summarize run steps, timeline events, handoffs, approvals, side effects, and execution bundle topology without adding durable interaction records in this spec.
The primary seeded run is `67676767-6666-4767-8767-000000000067` for Acme tenant `11111111-1111-1111-1111-111111111111`.

## What This Guide Covers
This guide covers environment setup, deterministic seed data, API validation, runtime graph evidence counts, cross-tenant denial, redaction checks, automated QA, Playwright evidence, curl regression, and acceptance notes.
It focuses on the existing operations workbench and the `GET /admin/runs/{workflow_run_id}/agent-graph` route.
It does not validate Spec 068 durable replay evidence; QA067 intentionally uses existing runtime tables only.
It does not require live model providers, Telegram delivery, external connectors, Auth0, or production secrets.

## How To Use This Guide
Run the commands in order from the repository root. Capture command output under `/tmp/qa067-*` and screenshots under `output/playwright/qa067_ui`.
Every check includes an Expected line and a What this proves line. Treat raw prompts, completions, provider payloads, channel messages, memory contents, secrets, raw tool payloads, local filesystem paths, or stack traces as failures.

## API Runtime Graph Checks
### API Check 1
```bash
curl --fail --silent -H "$QA067_HEADER" "$QA067_BASE_URL/admin/runs/$QA067_WORKFLOW_RUN_ID/agent-graph?tenant_id=$QA067_TENANT_ID" | tee /tmp/qa067-agent-graph.json | jq .provenance.evidence_counts
```
Expected: run steps, timeline events, handoffs, side effects, and approvals are counted.
What this proves: the route projects runtime graph evidence from existing tables.

### API Check 2
```bash
jq -e '.source == "runtime_run" and .provenance.workflow_run_id == env.QA067_WORKFLOW_RUN_ID' /tmp/qa067-agent-graph.json
```
Expected: jq exits 0.
What this proves: the response is tied to the seeded runtime run.

### API Check 3

What this proves: runtime node status overlay is visible.
