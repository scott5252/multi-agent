# QA046: User-Facing Run UI React Port And Jinja Removal

## Goal

Verify that the user-facing run browser surface is React-only, while the retained `/runs` JSON APIs continue to own workflow start, status, timeline, result, approvals, cancellation, subscriptions, callbacks, and artifact grants.
Expected: authenticated browser links never render the old Jinja run templates.
Expected: retained JSON APIs keep same-tenant access working and cross-tenant access fail-closed.
What this proves: Spec 046 can stay deleted ahead of the final Jinja infrastructure decommission.

## What This Guide Covers

- `/runs` and `/runs/new` redirect to `/admin/app/channels/runs`.
- `/runs/{run_id}` redirects to `/admin/app/channels/runs/{run_id}` after a safe access check.
- The React run workspace starts runs and loads safe status, timeline, result, action, and artifact sections.
- The retained APIs still support SSE, approval, cancellation, subscription, callback, and artifact grant flows.
- Scanner tests prove `TemplateResponse`, `Jinja2Templates`, and retired run template names stay absent from user-facing run routes.
Expected: reviewers can complete the whole pass using only local-principal identities and mock-safe local dependencies.

## Create A Same-Tenant Run

```bash
RUN_CREATE=/tmp/qa046-run-create.json
curl -sS -X POST http://127.0.0.1:8000/runs \
  -H "Content-Type: application/json" \
  -H "X-Local-Principal: tenant-admin-acme" \
  -H "X-Idempotency-Key: qa046-create-001" \
  -d '{"workflow_id":"qa046-browser-demo","inputs":{"topic":"safe qa046","_channel_state":"completed"},"channel":"web_api"}' \
  | tee "$RUN_CREATE"
RUN_ID=$(jq -r .run_id "$RUN_CREATE")
printf "%s\n" "$RUN_ID" | tee /tmp/qa046-run-id.txt
```

Expected: the response status is accepted, `run_id` is present, and `status_url` starts with `/runs/`.
Expected: the response does not include raw prompt text, raw completion text, callback secrets, or local paths.
What this proves: the retained JSON start API still owns run creation.

## Troubleshooting

- If local login fails, confirm `AUTH_MODE=local_principal` and `LOCAL_PRINCIPAL_COOKIE_NAME=map_local_principal` are present in `.env`.
- If `/runs` returns authentication errors, repeat the local login browser step or send `X-Local-Principal: tenant-admin-acme` for curl checks.
- If the generated contract check fails, run `uv run python scripts/frontend/generate_admin_react_types.py` and review the diff.
- If Playwright cannot find `Run workspace`, confirm the React assets were rebuilt with `cd frontend/admin && npm run build`.
- If artifact grant checks fail, recreate the deterministic completed run because artifact metadata is tied to that in-memory QA run.
- If cross-tenant denial returns success, stop and treat it as a security regression.
- If redaction grep finds raw prompt or raw payload strings, stop and inspect the UI/API response before continuing.
