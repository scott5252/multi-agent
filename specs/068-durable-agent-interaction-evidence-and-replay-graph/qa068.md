# QA068 Guide: Durable Agent Interaction Evidence And Replay Graph

## Goal
QA068 proves that durable runtime interaction evidence records a safe replay path for workflow runs and that the existing runtime graph can display that replay path without exposing protected payloads.
The feature adds an additive runtime evidence table and keeps the UI read-only. Reviewers should confirm that source and target node communication is visible as safe summaries, statuses, and references.
The primary seeded run is `68686868-6666-4868-8868-000000000068` for Acme tenant `11111111-1111-1111-1111-111111111111`.

## What This Guide Covers
This guide covers local environment setup, deterministic seed data, API validation, persistence checks, graph replay checks, redaction checks, tenant isolation, automated quality gates, curl regression, and evidence collection.
It focuses on the existing operations workbench and the existing `/admin/runs/{workflow_run_id}/agent-graph` route.
It does not ask reviewers to call live providers, Telegram, Auth0, external connectors, or production services.
It does not validate raw transcript storage because raw transcript storage is intentionally out of scope.

## How To Use This Guide
Run the setup commands in order, then perform the API and browser checks. Capture command output under `/tmp/qa068-*` so the evidence can be reviewed without containing private payloads.
Each numbered check includes an Expected line and a What this proves line. Treat any raw prompt, completion, credential, provider response, private channel payload, memory content, stack trace, or raw tool output as a failure.

## API Replay Checks
### API Check 1
```bash
curl --fail --silent -H "$QA068_HEADER" "$QA068_BASE_URL/admin/runs/$QA068_WORKFLOW_RUN_ID/agent-graph?tenant_id=$QA068_TENANT_ID" | tee /tmp/qa068-agent-graph.json | jq .provenance.evidence_counts
```
Expected: `interaction_evidence` is at least 5 and `unmapped_interaction_evidence` is at least 1.
What this proves: the graph route loads durable replay records and reports unmapped evidence honestly.

### API Check 2
```bash
jq -e '[.edges[].references[]? | select(.reference_type == "interaction_evidence")] | length >= 2' /tmp/qa068-agent-graph.json
```
Expected: jq exits 0.
What this proves: mapped replay evidence is attached to graph edges.

### API Check 3
```bash
jq -e '.. | strings | test("raw prompt|provider response|credential|stack trace|raw tool output"; "i") | not' /tmp/qa068-agent-graph.json
```
Expected: jq exits 0 for the visible response scan.
What this proves: the API response excludes protected marker text.
