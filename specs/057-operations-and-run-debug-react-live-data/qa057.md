# QA057: Operations And Run Debug React Live Data

## Goal

Prove qa057 replaces deterministic operations workbench and run-debug React
payloads with live persisted operations, audit, runtime, reliability, gateway,
delivery, and export evidence.

Expected: a seeded Acme scope shows live operational evidence from the database.

Expected: a Globex scope shows truthful empty states.

Expected: direct run-debug requests resolve the requested live run only.

Expected: browser and API export actions persist audit/export evidence and show
safe `operations-export:UUID` references.

Expected: platform-only pressure does not appear in tenant-admin output.

Expected: raw secrets, credential values, authorization headers, prompts,
completions, memory content, raw run details, private messages, connector
details, local paths, stack traces, and unauthorized tenant labels are absent.

What this proves: qa057 removes the fixed QA029 workbench projection instead of
moving it behind a new production helper.

## What This Guide Covers

This guide covers the local QA environment for `multi_agent_platform_qa057`.

It validates these React operations routes:

- `/admin/app/operations`
- `/admin/app/operations.json`
- `/admin/app/operations/runs/{workflow_run_id}.json`
- `/admin/app/operations/export`

It validates these database tables:

- `audit_timeline_events`
- `audit_runtime_trace_records`
- `gateway_invocation_attempts`
- `reliability_capacity_snapshots`
- `audit_inspection_access_events`
- `tenants`

Expected: Acme has three audit timeline rows inside the default 60-minute
window.

Expected: Acme has one gateway attempt for the seeded run.

Expected: Acme has two runtime trace rows for tool and Telegram delivery
evidence.

Expected: Globex has zero audit timeline rows.

Expected: export metadata is persisted through an audit inspection access row.

What this proves: the workbench, run-debug page, export panel, API responses,
and verifier inspect the same live database state.

## Troubleshooting

If the workbench has zero Acme logs, rerun `scripts/qa/seed_operations_qa057.py`
and confirm the QA database name in `.env`.

If export status is `unavailable`, confirm `FILESYSTEM_STORAGE_ROOT` exists and
is writable.

If a tenant-admin request returns 403, confirm the tenant ID in the URL matches
the local principal catalog.

If the browser shows old JavaScript, rebuild React assets through Spec QA or
clear the browser cache.

If redaction grep finds a forbidden term, treat it as a blocker and inspect the
API response before collecting screenshots.
