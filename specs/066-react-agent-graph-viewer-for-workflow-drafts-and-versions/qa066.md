# QA066 Guide: React Agent Graph Viewer For Workflow Drafts And Versions

## Goal

Validate that Spec 066 renders backend-owned Agent Communication Graph data in
the React Admin workflow experience.
The viewer must show a read-only graph for drafts.
The viewer must show a read-only graph for published versions.
The viewer must include keyboard-readable node and edge lists.
The viewer must expose safe selected node and edge details.
The viewer must preserve existing workflow builder surfaces.
The viewer must never create fake production graph records.
The viewer must never show protected raw payloads.
Expected: qa066 proves the graph viewer is usable, typed, tenant-safe, and redaction-safe.

## What This Guide Covers

This guide covers deterministic qa066 setup.
It covers the dedicated qa066 database.
It covers local-principal sign-in.
It covers the QA seed workflow.
It covers generated React Admin API type freshness.
It covers draft graph UI checks.
It covers published version graph UI checks.
It covers selected node and edge details.
It covers accessible list alternatives.
It covers desktop and mobile Playwright evidence.
It covers redaction scans.
It covers repository quality gates.
Expected: a reviewer can reproduce the same evidence from a clean database.

## How To Use This Guide

Run commands from the repository root.
Use `.env.qa066`.
Store command output under `/tmp/qa066-*`.
Store screenshots under `output/playwright/qa066_ui`.
Store local artifacts under `.data/qa066-artifacts`.
Use safe IDs and statuses in reviewer notes.
Do not paste raw prompts, completions, provider payloads, secrets, private messages, memory contents, or raw tool outputs into notes.
What this proves: the visible graph is derived from durable workflow records and safe backend graph contracts.

## Environment

Copy the environment file.

```bash
cp specs/066-react-agent-graph-viewer-for-workflow-drafts-and-versions/.env.qa066 .env
```

Expected: `.env` points to `multi_agent_platform_qa066`.

Create evidence directories.

```bash
mkdir -p .data/qa066-artifacts/evidence output/playwright/qa066_ui /tmp/qa066-evidence
```

Expected: qa066 artifact and screenshot directories exist.

Start PostgreSQL.

```bash
docker compose up -d postgres
```

Expected: the local PostgreSQL container is running.

Reset the database.

```bash
docker compose exec -T postgres sh -c 'dropdb -U postgres --if-exists multi_agent_platform_qa066 && createdb -U postgres multi_agent_platform_qa066'
```

Expected: only the qa066 database is reset.

Install dependencies and migrate.

```bash
uv sync
uv run alembic upgrade head
```

Expected: migrations finish without live provider, Telegram, Auth0, or connector calls.

Seed the graph viewer workflow.

```bash
uv run python scripts/qa/seed_agent_graph_viewer_qa066.py | tee /tmp/qa066-seed.txt
```

Expected: the output includes the fixed draft and version IDs.

Start the API.

```bash
uv run uvicorn multi_agent_platform.api.main:app --host 127.0.0.1 --port 8000 | tee /tmp/qa066-api.log
```

Expected: the API listens on `127.0.0.1:8000`.

## Backend Graph Sanity Checks

Fetch the draft graph.

```bash
curl -sS -H "$ACME_HEADER" "$BASE_URL/admin/workflows/drafts/$QA066_DRAFT_ID/agent-graph" | tee /tmp/qa066-draft-agent-graph.json
```

Expected: the draft graph request returns JSON.

Validate draft graph categories.

```bash
jq -e '.source == "draft" and .partial == false and ([.nodes[].category] | index("coordinator_agent") != null and index("sub_agent") != null and index("tool") != null and index("join") != null and index("approval") != null and index("handoff") != null and index("terminal") != null)' /tmp/qa066-draft-agent-graph.json
```

Expected: all required draft node categories are present.

Fetch the published graph.

```bash
curl -sS -H "$ACME_HEADER" "$BASE_URL/admin/workflows/versions/$QA066_VERSION_ID/agent-graph" | tee /tmp/qa066-version-agent-graph.json
```

Expected: the published graph request returns JSON.

Validate published graph provenance.

```bash
jq -e '.source == "published_version" and .provenance.workflow_version_bundle_id == env.QA066_VERSION_ID' /tmp/qa066-version-agent-graph.json
```

Expected: published graph provenance points at the seeded version.

## Troubleshooting

- If seeding fails, confirm `.env.qa066` is active and migrations are applied.
- If the draft page is empty, rerun `uv run python scripts/qa/seed_agent_graph_viewer_qa066.py`.
- If graph fetches return `403`, confirm Acme tenant admin is selected in local login.
- If graph fetches return `404`, confirm the fixed QA IDs match the seed output.
- If generated types are missing, rerun the generator and inspect `scripts/frontend/generate_admin_react_types.py`.
- If typecheck fails, inspect `AgentGraphPanel.tsx` and generated graph interfaces.
- If desktop screenshot has overlap, inspect `agent-graph-layout` and `agent-graph-canvas` CSS.
- If mobile screenshot has overlap, inspect the responsive `agent-graph-layout` rule.
- If unsafe text appears, fix the source graph field or frontend rendering path before continuing.
- If curl regression fails, inspect the first failing command under `.data/curl_test_runs/qa066-after-spec`.
