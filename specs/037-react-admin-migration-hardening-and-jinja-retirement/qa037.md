# QA037: React Admin Migration Hardening And Jinja Retirement

## Goal

Validate the final React admin migration hardening pass for `/admin/app` and `/admin/app/migration`.

This guide proves that React is the primary admin landing experience while retained fallback routes stay available until retirement evidence is complete.

This guide also proves that rollback instructions, route parity rows, performance budgets, accessibility evidence, redaction sweeps, and tenant isolation summaries are available without exposing unsafe payloads.

QA037 uses `AUTH_MODE=local_principal`, deterministic Acme and Globex tenants, fake local secret references, and the isolated database `multi_agent_platform_qa037`.

No command in this guide should contact real Auth0, Telegram, model providers, external tools, production databases, or production credential systems.

## What This Guide Covers

- React shell and migration home access for `/admin/app`.
- Direct migration dashboard access for `/admin/app/migration`.
- Platform administrator visibility across every migration route group.
- Tenant administrator visibility limited to tenant-safe and mixed route groups.
- Tenant user visibility limited to user-safe migration guidance.
- Route parity matrix coverage for Specs 026 through 036.
- Retained fallback and rollback evidence for cautious Jinja retirement.
- Performance budget, accessibility audit, redaction sweep, and tenant isolation sweep panels.
- Cross-tenant denial for Acme users trying to request Globex scope.
- Focused backend tests, frontend checks, generated TypeScript contracts, full project quality gates, and Playwright screenshots.
