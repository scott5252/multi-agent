# QA021: Real Skill Tool Execution Connectors

## Scope

This guide validates the governed SkillExecutionGateway and Daily Briefing
read-only adapters for calendar, Gmail, news, weather, and commute tool calls.
The QA path uses local mock fixtures and safe credential metadata. It must not
contact Google, Gmail, news, weather, traffic, or production providers.

## Environment

Use `specs/021-real-skill-tool-execution-connectors/.env.qa021` as the local
QA environment file. It configures local-principal auth, the QA database
`multi_agent_platform_qa021`, filesystem artifact storage under
`.data/qa021-artifacts`, and local users with `skill-execution:read`.

## Setup

```bash
test ! -f .env || cp .env .env.autopilot-backup
cp specs/021-real-skill-tool-execution-connectors/.env.qa021 .env
uv sync
docker compose up -d postgres
docker compose exec -T postgres sh -c 'dropdb -U postgres --if-exists multi_agent_platform_qa021 && createdb -U postgres multi_agent_platform_qa021'
uv run alembic upgrade head
mkdir -p .data/qa021-artifacts output/playwright/qa021_ui
```

## Start Processes

```bash
uv run uvicorn multi_agent_platform.api.main:app --host 127.0.0.1 --port 8000
uv run python -m multi_agent_platform.workers.main
```

## API Checks

```bash
curl --fail --silent http://127.0.0.1:8000/health/live
curl --fail --silent http://127.0.0.1:8000/health/ready
curl --fail --silent http://127.0.0.1:8000/version
curl --fail --silent http://127.0.0.1:8000/dependencies
curl --fail --silent -H "X-Local-Principal: platform-admin" http://127.0.0.1:8000/admin/skill-execution/api/diagnostics
```

## Expected API Results

- Health endpoints return HTTP 200.
- Diagnostics returns five items.
- Items include Google Calendar Events, Gmail Messages, News Search, Weather
  Forecast, and Commute Lookup.
- Each item reports mock mode readiness.
- Summaries are redacted and contain no raw provider token or secret value.

- Verify denied policy cases happen before adapter invocation in unit tests.
- Verify mock diagnostics do not require live credentials.
- Verify credential references are represented only as safe metadata.
- Verify raw email bodies and sensitive query strings are redacted.
- Verify local live-probe requests are denied.
