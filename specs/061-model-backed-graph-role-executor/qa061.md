# QA061 Guide: Spec 061 - Model-Backed Graph Role Executor

## Goal

This guide verifies the model-backed graph role executor.

Spec 061 keeps deterministic role execution as the default.

Spec 061 adds a governed model-backed role execution path for workflow graph role nodes.

The model-backed path must use `ModelGateway`.

The model-backed path must use mocked provider behavior in local QA.

The executor must resolve tenant-scoped prompt, profile, model, policy, and provider evidence before a model call can happen.

The executor must build model input from safe summaries and artifact references.

The executor must validate structured output before graph success.

The executor must return safe `RoleExecutionResult` metadata.

The executor must fail closed when tenant scope, pins, policy, credentials, gateway response, redaction, or output contracts are invalid.

Expected: deterministic graph execution still passes without model-backed configuration.

Expected: mocked model-backed graph execution reaches `ModelGateway`.

Expected: mocked model-backed output includes safe usage and provenance.

Expected: malformed model output fails the role node safely.

Expected: unsafe text does not appear in stored output, logs, screenshots, or QA evidence.

Expected: no real provider credential is needed.

Expected: no live Auth0, Telegram, connector, provider, credential, or outbound call is required.
