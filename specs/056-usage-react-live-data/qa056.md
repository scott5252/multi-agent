# QA056: Usage React Live Data

## Goal

Prove qa056 replaces deterministic usage React payloads with live persisted
usage, pricing, export, tenant label, and confidence-state evidence.

Expected: an empty tenant shows a truthful empty usage state.

Expected: a seeded tenant shows only persisted Acme usage rows.

Expected: the dashboard totals are computed from `llm_usage_events`.

Expected: the browser and API create durable `usage_export_requests` rows.

Expected: artifact references use `usage-export:UUID` style values in API and
browser output, while storage URIs remain backend-only.

Expected: Globex remains empty and never sees Acme usage rows.

Expected: raw prompts, completions, authorization headers, memory payloads,
credential values, and local file paths are not rendered.

What this proves: qa056 removes the fixed QA035 usage data path instead of
moving deterministic data into another production helper.

## What This Guide Covers

This guide covers the local QA environment for `multi_agent_platform_qa056`.

It validates these React usage routes:

- `/admin/app/usage`
- `/admin/app/usage/bootstrap.json`
- `/admin/app/usage/events.json`
- `/admin/app/usage/exports`
- `/admin/app/usage/exports/{usage_export_request_id}.json`

It validates these database tables:

- `llm_usage_events`
- `llm_pricing_versions`
- `usage_export_requests`
- `tenants`

Expected: Acme has two usage events inside the default last-30-days window.

Expected: one Acme event has confirmed token counts and estimated cost.

Expected: one Acme event has partial usage and missing pricing metadata.

Expected: Globex has zero usage events.

Expected: the seeded export row is rendered as a safe reference only.

What this proves: the dashboard, drilldown, export panel, and API responses all
read the same live database state.

## Troubleshooting

If the API shows no usage events, rerun the seed command.

```bash
uv run python scripts/qa/seed_usage_qa056.py
```

Expected: Acme usage rows are restored.

If export creation fails, confirm filesystem storage root exists.

```bash
mkdir -p .data/qa056-artifacts
```

Expected: export storage can create nested artifact keys.

If tenant login fails, confirm local principals are loaded.

```bash
grep 'tenant-admin-acme' .env
```

Expected: the principal catalog contains `tenant-admin-acme`.

If the verifier fails before Playwright, create an export with the API command
in this guide or run the Playwright flow.

Expected: the verifier only passes after a post-seed export exists.

If a redaction scan fails, preserve the failing output and stop validation.

Expected: raw secrets, prompt bodies, local file paths, and unauthorized tenant
rows are blockers.
