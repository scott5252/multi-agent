# QA053 Guide: Test Bench React Live Data

## Goal

Prove qa053 replaces deterministic test bench React payloads with live
repository-backed suites, cases, assertions, runs, run steps, artifacts, publish
requirements, and safe audit-style evidence.

Expected: an empty tenant shows an explicit empty state.

Expected: a seeded tenant shows only persisted test bench records.

Expected: the React page can save a suite through the backend.

Expected: the database shows the saved suite revision after the browser action.

Expected: no raw prompt, raw completion, raw transcript, provider token,
credential value, connector payload, local path, or unauthorized tenant label is
rendered.

What this proves: qa053 removes the fixed QA033 and QA043 production test bench
rows instead of moving them into a new production helper.

## What This Guide Covers

This guide covers the local QA environment for `multi_agent_platform_qa053`.

It validates these React test bench routes:

- `/admin/app/test-bench`
- `/admin/app/test-bench/bootstrap.json`
- `/admin/app/test-bench/suites`
- `/admin/app/test-bench/runs.json`
- `/admin/app/test-bench/runs/{run_id}.json`
- `/admin/app/test-bench/gates.json`
- `/admin/app/test-bench/audit.json`
- `/admin/app/test-bench/artifacts/{artifact_reference_id}.json`

Expected: each JSON route can show live data or an explicit empty state.

Expected: Acme can see the QA053 seeded suite.

Expected: Globex sees an empty state and cannot see Acme rows.

Expected: artifact responses expose governed metadata only.

Expected: publish-gate evidence is derived from persisted requirements and runs.

What this proves: the live-data replacement includes route behavior, tenant
isolation, artifact safety, and publish-gate freshness.

Copy the QA environment.

```bash
cp specs/053-test-bench-react-live-data/.env.qa053 .env
```

```bash

```

Start PostgreSQL.

```bash
docker compose up -d postgres
```

Expected: the local PostgreSQL container is running.

Reset only the qa053 database.

```bash
docker compose exec -T postgres sh -c 'dropdb -U postgres --if-exists multi_agent_platform_qa053 && createdb -U postgres multi_agent_platform_qa053'
```

Expected: only `multi_agent_platform_qa053` is dropped and recreated.

Run migrations.

```bash
uv run alembic upgrade head
```

Expected: Alembic reaches the latest revision.

Seed local tenants.

```bash
docker compose exec -T postgres psql -U postgres -d multi_agent_platform_qa053 -v ON_ERROR_STOP=1 -c "INSERT INTO tenants (tenant_id, slug, display_name, status, created_at, updated_at) VALUES ('11111111-1111-1111-1111-111111111111', 'acme', 'Acme', 'active', CURRENT_TIMESTAMP, CURRENT_TIMESTAMP), ('22222222-2222-2222-2222-222222222222', 'globex', 'Globex', 'active', CURRENT_TIMESTAMP, CURRENT_TIMESTAMP) ON CONFLICT (slug) DO NOTHING"
```

Expected: Acme and Globex tenant rows exist.

Seed qa053 test bench records.

```bash
uv run python scripts/qa/seed_test_bench_qa053.py
```

Expected: the command prints `Seeded QA053 test bench live records`.

Create artifact directories.

```bash
mkdir -p .data/qa053-artifacts output/playwright/qa053_ui
```

Expected: QA artifact directories exist.

Start the app.

```bash
uv run uvicorn multi_agent_platform.api.main:app --host 127.0.0.1 --port 8000
```

Expected: the API is reachable on `http://127.0.0.1:8000`.

## Troubleshooting

If the app cannot connect to the database, confirm `.env` is copied from
`.env.qa053`.

If the Acme route is empty, rerun `uv run python scripts/qa/seed_test_bench_qa053.py`.

If Globex shows the Acme suite, stop and investigate tenant filters.

If Playwright cannot click `Save suite`, inspect `/tmp/qa053-api.log`.

If the post-UI verifier reports suite revision 2, Playwright did not persist
the suite-save action.

If artifact routes show storage details, stop and inspect artifact projection.

If generated types are stale, run the generator and rebuild the frontend.

If the curl test fails, treat it as a spec blocker.

Expected: repair work stays inside the active spec surface.

Expected: no real provider, Telegram, credential, or connector call is needed.
