# QA049: React Contract Provenance And Sample Route Retirement

## Goal

Prove qa049 adds backend-owned provenance, truthful empty-state metadata, and generated action metadata contracts while retiring the production sample patterns route.

This guide proves five outcomes.

- React admin shell states expose safe provenance and empty-state metadata.
- Generated TypeScript contracts include provenance, empty-state, and action metadata types.
- `/admin/app/patterns` and its JSON, action, and export routes cannot return sample data.
- Production React source no longer uses fixed `qa0xx` idempotency or revision defaults.
- The live-data scanner maps remaining future-spec cleanup work without hiding generated contract regressions.

## What This Guide Covers

- Shared Pydantic contract validation for `ReactAdminPageProvenance`, `ReactAdminEmptyStateMetadata`, and `ReactAdminActionMetadata`.
- OpenAPI assertions for retired sample routes and new metadata components.
- FastAPI route checks for local-principal and Auth0-shaped principals.
- React router and App tests proving the retired patterns route is not rendered.
- Frontend helper coverage for generated idempotency and request metadata.
- Scanner coverage for retired route targets, generated contracts, and built assets.
- QA database isolation for `multi_agent_platform_qa049`.
- Browser evidence for bootstrap/search metadata and retired route behavior.
- Post-UI API checks that prove the browser is backed by backend JSON contracts.
- Curl regression coverage after qa049 validation.

## Troubleshooting

- If bootstrap returns 401, verify the `X-Local-Principal` header or use the local login page.
- If the retired patterns action returns 405, treat it as acceptable because the SPA fallback only allows GET.
- If search returns a patterns result, rerun route and navigation tests before continuing.
- If generated TypeScript check fails, rerun `uv run python scripts/frontend/generate_admin_react_types.py`.
- If frontend tests fail after regeneration, check fixtures for new nullable metadata fields.
- If the build warns about chunk size, record the warning; it is not a qa049 failure unless the build exits nonzero.
- If Playwright cannot start, verify port 8000 is free and `.env.qa049` is copied to `.env`.
- If redaction scan prints expected test-only fixture paths, confirm they are under `tests/` or `frontend/admin/src/test/`.
