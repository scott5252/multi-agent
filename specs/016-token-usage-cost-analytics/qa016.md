# QA016: Token Usage And Cost Analytics

## Goal

Validate that Spec 016 records normalized token usage and cost analytics for
ModelGateway-backed agents and sub-agents, renders safe admin dashboard views,
enforces tenant isolation, and creates audited CSV export metadata without
storing or displaying raw model content.

This guide is for reviewers who want command-by-command validation evidence.
The companion `qa016_ui.md` is browser-first. This guide covers setup,
environment checks, API checks, focused tests, quality gates, tenant isolation,
redaction, export safety, and evidence collection.

## What This Guide Covers

- Local setup for `multi_agent_platform_qa016`.
- Local-principal sign-in for platform, Acme, and Globex personas.
- ModelGateway usage normalization and capture tests.
- Admin dashboard route `/admin/usage`.
- JSON API routes under `/admin/usage/api`.
- Usage event filters for tenant, principal, provider, model, workflow, agent,
  sub-agent, prompt version, execution mode, status, and time range.
- Query-time rollups by day, hour, tenant, provider, model, workflow, agent,
  sub-agent, prompt, execution mode, and principal.
- CSV export request metadata and artifact storage under `.data/qa016-artifacts`.
- Denied cross-tenant access behavior.
- Redaction of raw prompts, completions, secrets, memory content, provider
  credentials, and unauthorized run content.
- QA docs validation, Ruff, mypy, focused tests, Playwright screenshots, and
  full coverage command.

## How To Use This Guide

Use two terminals from the repository root.

- Terminal A runs the API server and stays open.
- Terminal B runs setup, API checks, focused tests, and quality commands.
- Browser checks are described in `qa016_ui.md`.
- Save command output or reviewer notes under `/tmp/qa016-*`.
- Save browser screenshots under `output/playwright/qa016_ui`.
- Save generated CSV artifacts under `.data/qa016-artifacts`.

Important reviewer rule: stop if any command tries to reset a database other
than `multi_agent_platform_qa016`.

Important reviewer rule: stop if any command asks for a real provider API key.

Important reviewer rule: stop if any dashboard, export, log, or artifact shows
raw prompt text, raw completion text, a real secret, memory content, provider
credentials, or unauthorized run content.

## Troubleshooting

- `401 missing local principal`: sign in through local login or send
  `X-Local-Principal`.
- `403 tenant scope is not authorized`: verify the active principal and tenant
  id match.
- Empty dashboard: valid before usage events exist; verify the safe empty
  state and focused seeded tests.
- Export has zero rows: filters may not match seeded usage events.
- Export denied: confirm tenant scope and principal role.
- Database errors: confirm `.env` contains `multi_agent_platform_qa016`.
- Artifact write errors: confirm `.data/qa016-artifacts` exists and is writable.
- Playwright screenshots missing: rerun the Playwright validation command.
- Redaction failure: stop and report the exact page, export, or artifact path.
