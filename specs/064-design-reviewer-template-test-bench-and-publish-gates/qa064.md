## Troubleshooting

If PostgreSQL is unavailable, run `docker compose up -d postgres` and retry.
If migrations fail, capture the migration name and safe error summary.
If local login fails, confirm `AUTH_MODE=local_principal`.
If the install route returns 403 for Acme, confirm the Acme principal has tenant admin rights.
If the install route returns 403 for Globex targeting Acme, that is expected.
If the workspace does not show ready state, rerun the qa064 seed script.
If evidence appears stale, confirm no newer workflow draft revision was created after the evidence run.
If Playwright cannot find text, inspect `/tmp/qa064-ui-seed.txt` and API logs.
If frontend build fails, rerun typecheck and review the first TypeScript error.
If curl regression fails, open the failing command output under `.data/curl_test_runs/qa064-after-spec`.
Expected: failures are investigated with safe logs and no raw model or secret payloads.
