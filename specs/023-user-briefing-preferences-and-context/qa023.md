# QA023: User Briefing Preferences And Context

## Goal

Validate that tenant-scoped Daily Intelligence Briefing preferences can be
saved, safely summarized, exported/imported, resolved for runtime, and attached
to Telegram natural-language briefing triggers without exposing raw credentials
or cross-tenant profile data.

## What This Guide Covers

- Local QA environment setup for `multi_agent_platform_qa023`.
- Browser profile save flow at `/admin/briefing-preferences`.
- JSON API profile save, summary, export, import, and runtime resolve checks.
- Tenant isolation checks for Acme and Globex principals.
- Redaction checks for VIP senders and account references.
- Telegram alias context injection for `Morning briefing`.
- Focused automated tests and full quality gates.

## API Validation

Save a profile:

```bash
curl --fail --silent -X POST "$BASE_URL/admin/briefing-preferences/api/profile" \
  -H "$ACME_HEADER" -H 'Content-Type: application/json' \
  --data '{"tenant_id":"11111111-1111-1111-1111-111111111111","location_label":"Providence, RI","timezone":"America/New_York","news_topics":["AI","markets"],"vip_senders":["sarah@example.com"],"workday_start":"09:00","workday_end":"17:30","commute_mode":"driving","calendar_account_ref":"delegated:calendar:primary","email_account_ref":"delegated:gmail:primary","output_style":"standard","scheduled_enabled":true,"scheduled_time":"08:00"}' \
  | tee /tmp/qa023-profile.json
```

Expected: response contains `revision_number`, `revision_token`,
`content_digest`, and safe summary metadata.

Read safe summaries:

```bash
curl --fail --silent "$BASE_URL/admin/briefing-preferences/api/summaries?tenant_id=$ACME_TENANT" \
  -H "$PLATFORM_HEADER" | tee /tmp/qa023-summaries.json
```

Expected: summary includes `s***@example.com` and `delegated:***`; it does not
include `delegated:calendar:primary`.

Resolve runtime context:

```bash
curl --fail --silent -X POST "$BASE_URL/admin/briefing-preferences/api/resolve" \
  -H "$ACME_HEADER" -H 'Content-Type: application/json' \
  --data '{"tenant_id":"11111111-1111-1111-1111-111111111111","principal_id":"tenant-admin-acme","source_channel":"telegram","trace_id":"trace-qa023"}' \
  | tee /tmp/qa023-resolve.json
```

Expected: `available` is true, `revision_id` is present, and preferences include
`America/New_York`.

Verify tenant isolation:

```bash
curl --silent --output /tmp/qa023-denied.json --write-out '%{http_code}\n' \
  "$BASE_URL/admin/briefing-preferences/api/profile?tenant_id=$ACME_TENANT" \
  -H "$GLOBEX_HEADER"
```

Expected: HTTP `403`.
